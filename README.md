# zcarecrow.github.io

Forwards to the [CourseForge documentation](https://zcarecrow.github.io/CourseForge/).

GitHub Pages paths are case-sensitive and the project site lives at `/CourseForge/`.
This user site catches every other spelling - `/courseforge`, `/Courseforge/quick-start/` -
in `404.html` and sends it on with the rest of the address, and `/` forwards to the
documentation as well. The documentation itself is built from
[ZcarecroW/CourseForge](https://github.com/ZcarecroW/CourseForge) (`docs/`).
