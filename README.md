# zcarecrow.github.io

Forwards to the [CourseForge documentation](https://zcarecrow.github.io/CourseForge/), the
[Flash2SVG user guide](https://zcarecrow.github.io/Flash2Svg/), the
[HighBazar documentation](https://zcarecrow.github.io/HighBazar/) and the
[TTV-TTS documentation](https://zcarecrow.github.io/TTV-TTS/).

GitHub Pages paths are case-sensitive and the project sites live at `/CourseForge/`,
`/Flash2Svg/`, `/HighBazar/` and `/TTV-TTS/` (that repo was called `ttv-tts` until 2026-11-01).
This user site catches every other spelling - `/courseforge`, `/flash2svg/quick-start.html`,
`/ttv-tts/readme.html` - in `404.html` and sends it on with the rest of the address
(`courseforge/`, `flash2svg/`, `highbazar/` and `ttv-tts/` forward their bare address), and `/`
forwards to the CourseForge documentation. The sites themselves are built from
[ZcarecroW/CourseForge](https://github.com/ZcarecroW/CourseForge) (`docs/`),
[ZcarecroW/Flash2Svg](https://github.com/ZcarecroW/Flash2Svg) (`docs/guide/`),
[ZcarecroW/HighBazar](https://github.com/ZcarecroW/HighBazar) (`docs/site/`) and
[ZcarecroW/TTV-TTS](https://github.com/ZcarecroW/TTV-TTS).
