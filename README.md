# zcarecrow.github.io

Forwards to the [CourseForge documentation](https://zcarecrow.github.io/CourseForge/) and the
[Flash2SVG user guide](https://zcarecrow.github.io/Flash2Svg/).

GitHub Pages paths are case-sensitive and the project sites live at `/CourseForge/` and
`/Flash2Svg/`. This user site catches every other spelling - `/courseforge`,
`/flash2svg/quick-start.html` - in `404.html` and sends it on with the rest of the address
(`courseforge/` and `flash2svg/` forward their bare address), and `/` forwards to the CourseForge
documentation. The sites themselves are built from
[ZcarecroW/CourseForge](https://github.com/ZcarecroW/CourseForge) (`docs/`) and
[ZcarecroW/Flash2Svg](https://github.com/ZcarecroW/Flash2Svg) (`docs/guide/`).
